# skyshot · 天空快照

ESP32 天空 / 落日实时渲染器：按真实时间与本机经纬度，把「此刻头顶的天空」渲染到小屏上，
包括太阳、月亮和亮星。不依赖外部字体 / 库，网页配置页 gzip 后内嵌在固件里。

仓库按开发板分目录，每个目录都是完整独立的 PlatformIO 工程：

| 目录 | 硬件 | 屏幕 |
| --- | --- | --- |
| [ESP32C6](ESP32C6/) | 微雪 ESP32-C6-LCD-1.3 | ST7789 **240×240** 方屏（早期版本） |
| [ESP32S3](ESP32S3/) | 微雪 ESP32-S3-LCD-2.8 | ST7789 **320×240** 横屏            |

> ESP32S3 横屏**不是**把 240×240 直接拉伸铺满：投影缩放只与屏幕**高度**绑定，
> 320 宽的 80 列按同一等角立体投影真实渲染更宽的方位角，星点 / 太阳 / 月亮始终是正圆。

构建与使用说明见各子目录的 README。
